# lp-odontologia-estetica

Landing page de agendamento para clínica de odontologia estética. A página conduz o visitante até o agendamento da avaliação, com prova social, FAQ e um único botão de ação repetido ao longo da rolagem.

## Demonstração

Esta é a versão de demonstração de uma página entregue a cliente. Marca, profissional, textos, contatos e imagens são fictícios. Nenhuma foto de paciente, dado clínico ou registro profissional real foi publicado. A arquitetura, o CSS, o JavaScript e a estrutura de conversão são os mesmos do projeto original.

## Problema

A clínica dependia de mensagens diretas para agendar. Quem chegava pelo anúncio não encontrava um lugar que explicasse o procedimento, respondesse dúvidas de preço e prazo e levasse ao agendamento sem conversa prévia.

## O que a página faz

**Caminho único.** Um botão de agendamento, repetido nas seções-chave e fixo no rodapé do celular.

**Prova social.** Seção de casos e depoimentos, estruturada para receber conteúdo com autorização.

**FAQ de objeção.** Preço, prazo, pagamento e localização respondidos antes do contato.

**SEO e compartilhamento.** Meta tags Open Graph, canonical e dados estruturados schema.org do tipo negócio local.

**Rastreio preparado.** Pontos de instalação de Meta Pixel e GA4 marcados no código, sem IDs versionados.

## Stack

HTML · CSS · JavaScript · schema.org · layout responsivo, pensado primeiro para o celular

## Como usar

Abra `index.html` no navegador ou publique o arquivo em qualquer hospedagem estática. O arquivo é autocontido: CSS, JavaScript e imagens de exemplo estão embutidos.
